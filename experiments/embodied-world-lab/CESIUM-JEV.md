# Cesium × cesium-mcp × Jev 场景实验

本实验让橙色 RobotExpressive 人形角色在东京丸之内的真实纹理建筑区步行。当前默认任务的目标位于建筑另一侧：几何算法提供左右绕行候选，Jev 选择路线并持续决定短段动作，cesium-mcp Bridge SDK 传递选择与运动意图，Rapier 和本地控制器执行。

开发分支：`codex/cesium-jev-demo`。本地新入口：[东京建筑区](http://127.0.0.1:4192/?planner=jev&scene=city)。原 `4186` 演示保留，当前版本尚未部署公网。

## 本地运行

需要 Node.js 22 或更新版本。仅安装实验自己的依赖，在仓库根目录运行：

```powershell
rtk npm --prefix experiments/embodied-world-lab ci
```

在实验目录被 Git 忽略的 `.env.local` 中配置 `TYPESAFE_API_KEY`，然后启动：

```powershell
rtk npm --prefix experiments/embodied-world-lab run dev
```

页面默认选择 `city` 绕楼场景。等待场景、角色和碰撞数据就绪后再开始；加载页面不会自动导航。碰撞 JSON 已随实验保存，首次运行不必重新下载生成。建筑显示、影像和模型接口仍需要联网。密钥由本地 Vite 服务端读取，浏览器通过同源 `/api/jev/route` 请求路线选择、通过 `/api/jev/plan` 请求短段动作；不要将密钥放入前端配置或 Git。模型调用产生 API 用量，纯静态部署不包含服务端代理。

碰撞数据的准备脚本为 [`scripts/prepare-city-colliders.mjs`](scripts/prepare-city-colliders.mjs)。可先运行不联网、不改输出的坐标变换自测：

```powershell
rtk npm --prefix experiments/embodied-world-lab run prepare:city -- --self-test
```

需要重新生成数据时，运行不带 `--self-test` 的 `prepare:city`。该操作会从固定 PLATEAU 源下载选定叶节点、检查坐标与射线，并覆盖 `src/assets/tokyo-colliders.json`；不是每次启动的必需步骤。

## 绕楼路线由谁决定

当前预设的起终点直线距离约 **52 米**。几何检查发现，直连线前方约 **17.49 米**处会撞上 PLATEAU 建筑表面，因此需要绕行。

1. 本地算法将真实建筑网格保守投影到导航平面，再通过 A* 生成左右候选。当前候选折线路长分别约 **83.4 米**和 **81.9 米**；这是算法路线长度，不是已完成的角色行程。
2. Bridge 的 `readNavigationOptions` 提供候选路线与结构化摘要。Jev API 在 `left`、`right`、`hold` 中选择，结果通过 `commitNavigationRoute` 提交并校验。
3. 路线接受后，本地路线跟随器提供下一个拐点。Jev 继续依据距离、朝向与局部状态选择短段 `advance`、转向或停留；本地控制器执行并检查安全。

**候选坐标与 A* 搜索由程序计算，Jev 负责候选选择和短段行动决策。** 建筑信息来自已加载的城市网格，模型接收程序组织的结构化数据；没有从截图识别建筑，也没有让模型凭空生成整条路径。

## 连续行动怎样调整

旧版本的一段动作约两秒，到期后才等待下一次模型结果，因此会出现“走一段、停下来、再走”的节奏。当前循环在有效动作继续执行时提前请求下一段计划：

- 本实验配置提前最多 **3,000 毫秒**规划，提前窗口不超过当前动作时长的一半。
- 有效动作在等待响应期间继续执行；单次 `advance` 最长 **6 秒**。
- 转向已经对齐目标方向时，可提前结束转向，不必等满整段时长。
- 本地 **20 Hz** 安全循环继续检查风险、碰撞、计划有效性和停止请求，必要时干预动作。

这些调整消除了“必须等动作到期才请求”的安排。转向响应已调整，俯视相机也与人物朝向控制分离。原地转向、等待下一计划、模型超时或安全干预仍可能使角色停止平移；本轮结果不表述为整轮零停顿。

## 城市场景与数据边界

默认城市位于东京站西侧的丸之内街区，建筑来自 **国土交通省 Project PLATEAU 千代田区 2025 年度带纹理 LOD2 3D Tiles**。已纳入版本控制的 [`src/assets/tokyo-colliders.json`](src/assets/tokyo-colliders.json) 保存源地址、瓦片哈希、建筑标识、坐标编码与验证记录；生成过程见[准备脚本](scripts/prepare-city-colliders.mjs)。这是真实城市建筑数据，不是随机生成的楼群。

渲染建筑不会自动成为 Rapier 碰撞体。本实验已从同源 **16 个叶节点、132 个唯一源建筑标识**提取 **57,426 个三角形**并加载为碰撞网格，JSON 约 **5.19 MB**。转换保留源建筑几何，省去纹理与材质，应用源坐标变换后存为局部 ECEF 偏移；没有使用 OSM footprint 拉伸或建筑高程偏移。坐标变换、源包围区域、射线检查和本轮独立轨迹三角形审计已通过，结果仅覆盖本次记录的路线。

碰撞覆盖范围为 `[139.7630, 35.6790, 139.7665, 35.6830]`。与该范围相交的叶节点保留完整几何，范围之外不保证覆盖完整。数据仅包含建筑，不将建筑底面当成真实道路表面。

城市地面明确采用 **38 米椭球高的局部平面近似**，不是实测道路地形。东京附近 ArcGIS 高程样本约为 2.9 米，但服务声明使用正高；其基准与建筑数据存在差异，不能将该数值静默当作椭球高。建筑 mesh 不做高程偏移。角色和地面按该平面放置，这不代表真实道路坡度或测量精度。

## 观测、控制与其他场景

Bridge SDK 使用 `readNavigationOptions` / `commitNavigationRoute` 连接路线选择，使用 `observeWorld` / `commitMotionIntent` / `stopEmbodied` 连接短段观测、运动意图与停止。当前页面直接调用 `CesiumBridge` 执行通道，**尚未串联独立 MCP stdio/HTTP 客户端与 runtime 服务**。

Jev 接收候选路线摘要，以及目标距离、方位差、接地状态、速度和候选方向等结构化观测，返回类型化选择。请求使用 `jev-latest`，实际模型名以当次记录为准。角色采用步行胶囊控制与动画，本实验不实现车辆自动驾驶、真实机器人硬件控制或视觉识别。本地寻路、安全干预与路线跟随不能记为模型推理结果。

| `scene` | 配置 |
| --- | --- |
| `city` | 默认：东京丸之内真实建筑挡路，选择左绕、右绕或停留 |
| `inspection` | 旧山坡巡检起点、目标与人工风险布局 |
| `wide-detour` | 旧山地场景，扩大前方风险圆 |
| `near-risk` | 旧山地场景，将风险圆移近起点 |
| `random` | 在旧山地场景中按种子改变目标与人工风险圆 |

例如 [山坡巡检](http://127.0.0.1:4192/?planner=jev&scene=inspection&seed=260921) 与 [随机配置](http://127.0.0.1:4192/?planner=jev&scene=random&seed=846641)。随机化的是实验配置，不是东京建筑或真实地形；同种子重现布局，不保证同一行动序列。

历史滑块查看已记录的位置与观测，不调用模型，也不移动当前活角色；它不是重新执行物理模拟。运行记录通过“查看记录”打开只读 JSON，可全选后手动复制，无需浏览器下载或自动剪贴板支持。

行程与移动时间根据实际位置变化计算，不使用前进输入或期望速度冒充移动。统计中的续期静止还包含原地转向及等待下一计划，不能全部归因于网络卡顿，也不能据此宣称整轮零停顿。本轮切换俯视时，人物方位误差基本不变并继续行走，验证了相机切换与人物朝向控制的分离。

独立审计直接使用原始 PLATEAU 三角形，不依赖导航栅格。569 帧记录的最大时间间隔为 **118.5 毫秒**，相邻位置最大位移约 **0.2223 米**。相邻轨迹段在实际高度以及 38.7、39.5、40 米高度的四组相交检查中，均未发现穿过建筑三角形。

记录中心的采样点到真实建筑 mesh 的最小距离为 **5.624 米**，精确 XY 投影距离为 **5.617 米**。按 38 米地面、1.8 米身高和 0.3 米半径的身体近似建立外包球，并扣除审计采样间距余量后，身体表面与 mesh 的保守净距下界为 **4.373 米**。这些数字与栅格下界的计算方式不同，不能混用。

审计证明的是记录点连成的插值折线及上述身体近似；它不能覆盖记录间未观测到的曲线偏离，也不证明任意建筑区、任意路线都能通过。独立证据保存在 `artifacts/jev-detour-verified-run-mesh-audit.json`。

停止检查覆盖路线请求仍在等待的情况：按停止后没有任何模型决策提交，20 秒后人物位置完全未变。

本轮完整本地证据为 Git 忽略的 `artifacts/jev-detour-verified-run.json`。当前 **124 项测试、类型检查与生产构建通过**。这些结果说明本次预设路线已完成，不构成导航成功率基准或真实机器人、车辆的安全保证。
